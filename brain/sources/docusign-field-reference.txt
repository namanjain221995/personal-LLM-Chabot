DocuSign + Salesforce Integration

Complete Salesforce Field Reference

Techsara Solutions Inc. | All fields, their use case, and where they are used in the DocuSign integration

HOW TO READ THIS DOCUMENT

Each section covers one Salesforce object. For every field you will find: API name, data type, whether it existed before or was created new for this integration, its purpose/use case, its formula (if applicable), and exactly where in the integration it is used (which template, which step, which DocuSign feature). Fields are included if they are referenced in a Gen Template anchor text, Envelope Template merge field or recipient, Field Value Update, Dynamic Actions condition, or Salesforce Validation Rule that enforces the DocuSign workflow.

6. Key Rules for Correct Field Usage

RULE 1 — Date field pre-population: Never use a raw Salesforce Date field as the DocuSign Merge Field source when the tab has Date validation. Salesforce sends Date values as YYYY-MM-DD; DocuSign Date validation expects MM/DD/YYYY. Always use a Formula (Text) field for pre-population. On second sends, the formatted Text field prevents the "invalid date format" error.

RULE 2 — Writeback targets: Formula fields in Salesforce are read-only and cannot receive writeback from DocuSign. Always use a standard Text, Date, Currency, or Checkbox field as the writeback target field in the DocuSign Merge Field configuration.

RULE 3 — PersonEmail vs Email: For Person Account (Candidate object), always use PersonEmail (API: PersonEmail) — not Email. For User (CS Person), always use Email (API: Email) — not SenderEmail, not EmailEncodingKey, not Signature.

RULE 4 — OwnerId relationship traversal: The Lookup field OwnerId becomes "Owner" in merge field / relationship syntax (drop the "Id" suffix). Access CS Person name as Candidate__r.Owner.Name and CS Person email as Candidate__r.Owner.Email.

RULE 5 — Field Value Updates vs Merge Field Writeback: Merge Field writeback fires only when the envelope is fully Completed (all parties signed). Field Value Updates fire per-event (Sent, Completed, Voided) and are the correct tool for updating status/checkbox fields at intermediate stages such as marking an agreement as Sent before all parties have signed.

RULE 6 — Formula fields for currency display: Raw Currency fields in Salesforce pass as plain numbers to DocuSign. To display as $X,XXX.XX in the document, create a Formula (Text) field using the currency formatting formula and use that as the Merge Field source with Read Only enabled.

7. Custom Regex Validations on DocuSign Tabs

Applied in the Place Fields tagger: click the tab > right panel > Validation > Custom. The regex is evaluated by DocuSign when the signer fills the field. The signer cannot submit until validation passes.

  ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  Tab / Field Name        Regex Pattern                                         Accepts                                                        Validation Message to Display
  ----------------------- ----------------------------------------------------- -------------------------------------------------------------- ---------------------------------------------------------------
  Bank Account Number     ^\d{6,17}$                                            6 to 17 digits only — no letters, spaces, or symbols           Please enter a valid bank account number (6-17 digits)

  Bank Routing Number     ^\d{9}$                                               Exactly 9 digits                                               Please enter a valid 9-digit routing number

  Debit Amount (dollar)   ^\$[\d,]+(\.(\d{1,2}))?$                              $12,000.15 / $500 / $1,234,567.89 — dollar sign required       Please enter amount in format: $12,000.15

  USA Phone Number        ^(\+?1[-.\s]?)?\(?\d{3}\)?[-.\s]?\d{3}[-.\s]?\d{4}$   (123) 456-7890 / 123-456-7890 / +1 123-456-7890 / 1234567890   Please enter a valid US phone number. Example: (123) 456-7890

  Day of Month (1-31)     ^([1-9]|[12][0-9]|3[01])$                             1 through 31 — rejects 0 and 32+                               Please enter a number between 1 and 31

  SSN — Last 4 or Full    ^(\d{4}|\d{3}-\d{2}-\d{4}|\d{9})$                     1234 OR 123-45-6789 OR 123456789                               Please enter last 4 digits (1234) or full SSN (123-45-6789)

  SSN — Last 4 Only       ^\d{4}$                                               Exactly 4 digits                                               Please enter exactly 4 digits of your SSN
  ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
