- contract: §6.3 budget/backoff: 'when exhausted → DOWN, no further destructive action' is not honoured for POST /recover — manual recoveries skip the budget and the cooldown (controller.py:925; README.md line 86 documents the bypass as intentional). The contract has no manual exemption.

### [major] monitoring/engine-controller/controller.py:925
POST /recover (loopback, no auth) bypasses both the recovery budget and the cooldown: `if not manual:` wraps the only two gates, so an unbounded number of pair restarts can be driven from 127.0.0.1 — the contract's 'budget exhausted → no further destructive action' (§6.3) does not hold for the one mutation endpoint the controller exposes.

*Scenario:* Any process that can reach 127.0.0.1:9838 on the head — the four host-network containers (sf-local-ai-vllm-1, whisper, node-exporter, the old watchdog), any local shell user, or a script bug that retries cluster-recover.sh — POSTs {"category":"manual"} in a loop.
