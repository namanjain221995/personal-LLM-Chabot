# Prompts

Generated by `scripts/gen_prompts_doc.py` from `prompts/*.md`. Do not edit this file by hand: change the prompt file (and raise its `version`), then run `.venv/bin/python scripts/gen_prompts_doc.py`. `tests/test_prompts_doc.py` fails when this file is not current, and the script refuses to write it when a text changed while its version stayed the same.

Every text the models get from a prompt constant, and every line code writes into a nudge, the FIELD CHECK, the lookup footer, the Source line or the other-people line, is one file `prompts/<id>.md`: a front matter block (`id` = the file name, `version`, `name` and `module` = the Python name that binds the text and its module, `source`, `placeholders`, sometimes `fill`) and then the exact text. `sf_assistant.prompts` loads and checks each file once per process (id, integer version, placeholders = the text's `{name}` and `<<NAME>>` tokens, LF only, no byte order mark); the module binds the text at import to the same name the code used before the files existed. `{name}` tokens are filled by `knowledge_prompts.render` or `combine_user_message`, `<<NAME>>` tokens by `prompts.fill` (one pass: a value is never filled again). `tests/test_prompt_files.py` checks every file, its binding, that every text is byte for byte the notebook folder's (a deliberately changed one: the notebook text with exactly the edits `tests/prompt_changes.py` lists, version raised) and that every code-written line equals the old f-string.

## How the special files are filled

Most texts are bound as they are. These say how their text is used (the `fill` header):

- `records_chart_words`: `one line per word as '<key>: <text>', read into a dict by agent.charts (bound as this raw text), each filled with prompts.fill`
- `question_category_definitions`: `parsed into the dict CATEGORY_DEFINITIONS (one line per category, in order, as '- <category>: <definition>')`
- `question_gen_system`: `filled at import: <<CATEGORY_BLOCK>> = the text of question_category_definitions, <<TOOL_BLOCK>> = TOOL_NAMES joined with ', '`
- `code_merge_counted`: `one key: text line per part, read into a dict by agent.merge (bound as this raw text); each part is filled with prompts.fill`
- `combine_user`: `filled by combine_user_message in one pass (values are never filled again); {field_check} is '' or '\n\nFIELD CHECK:' + one '\n- <line>' per line (built in code)`
- `records_table_words`: `one line per word as '<key>: <text>', read into a dict by agent.tables (bound as this raw text); shown and not_all are filled with prompts.fill, UNIT with the records, groups or periods word; partial ends a period the result marks partial; by (the label line of a lines block right after another block) is filled with LABEL, a field label or a grain, and compared is that line for segments`
- `business_terms`: `one line per term as '<key>: <definition>', read into a dict by engine.business_terms; the hints show the definition`
